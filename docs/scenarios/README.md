# System Design Scenarios

No system-design scenario is implemented yet.

Future scenarios will be browser-only deterministic exercises labeled **SIMULATED**. Each scenario must define:

- Learning objective
- Pirate narrative and standard engineering terminology
- Initial state and assumptions
- Available decisions
- Deterministic state transitions
- Failure and recovery paths
- Accessibility behavior
- What the exercise proves
- What it does not prove
- Verification and rollback plan

The first proposed scenario will examine duplicate commands, timeout ambiguity, idempotency, and reconciliation without invoking a real payment system or external service.
